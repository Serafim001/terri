# Тьерри
В этом проекте представлена выпечка из кондитерской тьерри.

## Как установить
Для того, чтобы установить проект необходимо скопировать себе репозиторий на компютер и установить зависимости при помощи команды:
```
pip install -r requirements.txt
```
## Как Запустить проект
Для того, чтобы запустить проект, необходимо прописать в терминале команду:
```
python main.py
```
## Цель проекта
Код написан в образовательных целях.
